# BrickBreakerGame

A simple, classic Brick Breaker game implemented in Java.

## Overview

This is a small desktop game implemented in plain Java (no external frameworks). The game features paddle control, ball physics, multiple bricks, scoring, and particle effects.

## Key Features

- Classic brick-breaker gameplay
- Keyboard controls for paddle movement
- Multiple brick layout generated by `Mapgenerator.java`
- Simple ball physics and collision handling
- Particle effects for visual feedback (`Particle.java`)
- Single-file entry point: `Main.java` and gameplay logic in `Gameplay.java`

## Files of interest

- `src\Main.java` — application entry point
- `src\Gameplay.java` — game loop, rendering, and core game logic
- `src\Mapgenerator.java` — brick layout generator
- `src\Particle.java` — simple particle effects

## How to run (Windows - cmd.exe)

Open a command prompt in the project root (the folder that contains this README and the `src` folder), then run:

```bat
javac src\\*.java
java -cp src Main
```

If you prefer to compile into an `out` directory first:

```bat
javac -d out src\\*.java
java -cp out Main
```

## Controls

- Left arrow / A: move paddle left
- Right arrow / D: move paddle right
- (Other controls depend on the implementation in `Gameplay.java`)

## Development notes

- The project is intentionally minimal and uses the Java built-in rendering and event handling.
- No external dependencies are required.
